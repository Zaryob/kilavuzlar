# About

This repository contains Süleyman Poyraz’s working notes, originally written in Turkish, on software development and system administration.

Docker and Vim documents have been reorganised as guides. Older Linux, OpenCV and Caffe notes awaiting verification are kept in the [archive](arsiv/README.md). Each archived page describes its scope and omissions. Source review and practical testing are reported separately.

The site is generated with [Jekyll](https://jekyllrb.com/). Its templates and styles live in this repository. Content and source code are covered by the [MIT licence]({{ '/LICENSE' | relative_url }}).
